# Security policy

Please report security issues privately to work@royalpinto007.com with "AgentPostmortem security" in the subject. Do not open a public issue.

We aim to acknowledge reports within three working days and to agree a disclosure date with you.

AgentPostmortem runs scenarios against simulated services in process. It does not need credentials for the benchmark itself. Model mode reads provider keys from environment variables only; never put keys in scenario files or results.
